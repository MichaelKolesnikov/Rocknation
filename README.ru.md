# Rocknation

Неофициальное Android-приложение на Python + [Flet 1.0](https://flet.dev) для MP3-раздела
сайта https://rocknation.su/.

[English version](README.md)

- каталог групп: по буквам, по жанрам, с постраничной навигацией;
- поиск групп;
- страницы групп и альбомов;
- избранные группы и избранные альбомы (хранятся локально);
- онлайн-прослушивание в фоне: очередь, перемешивание, повтор, управление из шторки
  и с экрана блокировки;
- загрузка отдельного трека (в папку по умолчанию) и альбома целиком (в выбранную папку);
- скачанные треки проигрываются из памяти телефона, без интернета.

## Структура

```
src/                      приложение (точка входа — src/main.py)
  rocknation/api.py       парсер rocknation.su
  rocknation/player.py    очередь воспроизведения
  rocknation/downloader.py очередь загрузок
  rocknation/storage.py   избранное, загрузки, настройки (JSON)
  rocknation/views/       экраны
flet_bg_audio/            Flet-расширение: фоновый плеер (audio_service + just_audio)
tools/prepare_template.py патч шаблона сборки Flet для фонового воспроизведения
```

## Сборка APK

Нужны Python 3.10+, JDK 17 и Android SDK (Flutter `flet build` установит сам).

```bash
python -m venv .venv
.venv/bin/pip install -e ./flet_bg_audio -e ".[desktop]" "flet[all]==1.0.5"

# один раз и после каждого обновления Flet:
.venv/bin/python tools/prepare_template.py

.venv/bin/flet build apk --arch arm64-v8a
# результат: build/apk/
# (arm64-v8a также задана в pyproject.toml, так что флаг можно не указывать)
```

`prepare_template.py` скачивает официальный шаблон сборки Flet и вносит в него три правки,
без которых `audio_service` не работает: MainActivity наследуется от
`AudioServiceFragmentActivity`, в манифест добавляются media-сервис и receiver медиакнопок,
а также добавляется монохромная иконка уведомления.

## Иконка

Исходник — `src/assets/icon.svg`. `flet build` не умеет растрировать SVG, поэтому после
правки SVG нужно пересоздать `src/assets/icon.png`:

```bash
.venv/bin/pip install cairosvg
.venv/bin/python tools/render_icon.py
```

Фон адаптивной иконки Android задаётся в `pyproject.toml` (`adaptive_icon_background`).

## Запуск на компьютере (для разработки)

```bash
.venv/bin/flet run src/main.py
```

На десктопе музыка играет через `flet-audio`, без фонового режима и шторки:
расширение `flet_bg_audio` работает только в собранном приложении.

## Куда сохраняется музыка

- По умолчанию: `Музыка/Rocknation/<Группа>/<Год - Альбом>/`. На Android 11+ для этой папки
  не нужны разрешения.
- Альбом сохраняется в папку, выбранную при скачивании (это можно отключить в настройках).
- Чтобы сохранять в произвольные папки на Android 11+, выдайте приложению доступ ко всем
  файлам. Приложение само предложит это перед первым скачиванием и откроет системный
  экран; позже доступ можно включить в «Настройки → Доступ ко всем файлам».
